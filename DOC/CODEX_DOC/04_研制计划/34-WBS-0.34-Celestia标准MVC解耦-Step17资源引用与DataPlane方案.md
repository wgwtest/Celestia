# Celestia MVC Step17 ResourceRef and DataPlane Stabilization Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 稳定跨进程 View3D 使用的 `ResourceRef`、资源解析状态、cache key 和 DataPlane 入口，让 View3D 不依赖 Model 进程内资源。

**Architecture:** Step17 不扩大历史 Renderer 视觉保真范围，也不重写 Model 核心语义。Model 继续只输出 `scene.frame` 和 `ResourceRef`；View3D 负责把 `ResourceRef.relativePath` 安全解析到 content root，或把 `ResourceRef.dataPlaneKey` 解释为 DataPlane 引用；Runtime/assembly 只负责传递 content root 和 transport 配置。Step17 完成后，Model 输出协议进入冻结前状态，后续 Model 层变化必须带回归证据。

**Tech Stack:** C++17, CMake, doctest, PowerShell, existing `sceneprotocol`, `view3dresources`, `dataplane`, `tools/mvc` scans, `tools/regression` compatibility harness.

---

## 1. Scope And Boundary

Step17 只处理资源引用和数据路径稳定化：

```text
ResourceRef safety
ResourceRef cache key
View3D resource resolution state
required/optional missing resource reporting
ResourceRef.dataPlaneKey -> DataPlaneRef bridge
Model output freeze record
```

Step17 不处理：

```text
historical in-process Renderer parity
new OpenGL texture upload pipeline
full mesh/material renderer migration
large screenshot matrix expansion
Qt or Win32 frontend parity
remote-machine distributed runtime
```

大规模视觉场景矩阵只在 Step17 完成后进入 Step18。

## 2. Resource Classification Table

| Resource class | `ResourceRef.kind` | Owner process | Stable cache key source | Lifetime | Fallback | Error event | DataPlane eligibility |
| --- | --- | --- | --- | --- | --- | --- | --- |
| Texture | `texture` | View3D loads or acquires | `dataPlaneKey`, else `contentHash`, else `package/kind/relativePath` | content-root file or frame data block | placeholder material | `view.resourceMissing` when required | yes |
| Mesh | `mesh` | View3D loads or acquires | `dataPlaneKey`, else `contentHash`, else `package/kind/relativePath` | content-root file or frame data block | placeholder sphere | `view.resourceMissing` when required | yes |
| Catalog block | `catalog` | Model references, View3D may inspect | `dataPlaneKey`, else `contentHash`, else `package/kind/relativePath` | content-root file or data block | omit optional catalog-dependent visuals | `view.resourceMissing` when required | yes |
| Orbit sample block | `orbit-sample` | Model produces, View3D consumes | `dataPlaneKey`, else `contentHash`, else `package/kind/relativePath` | frame data block | hide optional orbit | `view.resourceMissing` when required | yes |
| Label atlas | `label-atlas` | View3D owns generated atlas | `dataPlaneKey`, else `contentHash`, else `package/kind/relativePath` | View3D cache | render text without atlas cache | `view.resourceMissing` when required | yes |
| Shader | `shader` | View3D owns | `contentHash`, else `package/kind/relativePath` | application/runtime | fallback shader | `view.resourceMissing` when required | no for Step17 |
| Material setting | `material` | View3D owns | `contentHash`, else `package/kind/relativePath` | frame or runtime cache | default material | `view.resourceMissing` when required | no for Step17 |

    std::string cacheKey;

};

std::string resourceCacheKey(const protocol::ResourceRef&);

Modify `src/celruntime/view3d/view3dresources.cpp` with these rules:

```cpp
bool
isSafeResourcePath(const std::filesystem::path& relative)
{
    if (relative.empty() || !relative.is_relative())
        return false;
    for (const auto& part : relative)
    {
        if (part == "..")
            return false;
    }
    return true;
}

std::string
resourceCacheKey(const protocol::ResourceRef& resource)
{
    if (!resource.dataPlaneKey.empty())
        return resource.dataPlaneKey;
    if (!resource.contentHash.empty())
        return resource.contentHash;
    return resource.package + "|" + resource.kind + "|" + resource.relativePath;
}

bool
isDataPlaneEligibleResourceKind(std::string_view kind)
{
    return kind == "texture" ||
           kind == "mesh" ||
           kind == "catalog" ||
           kind == "orbit-sample" ||
           kind == "label-atlas";
}
```

In `resolveSceneResources()`, set:

```cpp
entry.cacheKey = resourceCacheKey(resource);
entry.dataPlaneEligible = isDataPlaneEligibleResourceKind(resource.kind) && !resource.dataPlaneKey.empty();
entry.dataPlaneRef = dataPlaneRefFromResource(resource);

const std::filesystem::path relative{ resource.relativePath };
if (!isSafeResourcePath(relative))
{
    entry.status = View3DResourceStatus::Invalid;
    resolved.push_back(std::move(entry));
    continue;
}

if (!contentRoot.empty())
{
    entry.resolvedPath = contentRoot / relative;
    entry.exists = std::filesystem::exists(entry.resolvedPath);
}

if (entry.exists)
    entry.status = View3DResourceStatus::Resolved;
else
    entry.status = resource.required
        ? View3DResourceStatus::MissingRequired
        : View3DResourceStatus::MissingOptional;
```
