# Celestia MVC Step16 Real Controller Interaction Loop Implementation Notes

日期：2026-06-27

## 1. 目标

Step16 的目标是把 `View input -> Controller command -> Model state -> scene.frame -> View` 做成真实闭环。

本轮先后实现六条可验证交互闭环：

```text
View3D KeyDown Space
-> view.input
-> ControllerService
-> model.setPaused
-> ModelService paused state
-> scene.frame time.paused=true
-> View3D view.frameRendered

View3D KeyDown L
-> view.input
-> ControllerService
-> model.setTimeScale
-> ModelService timeScale state
-> scene.frame time.timeScale=2
-> View3D view.frameRendered

View3D MouseWheel
-> view.input
-> ControllerService
-> model.setCameraFov
-> ModelService camera FOV output state
-> scene.frame camera.fov=40
-> View3D view.frameRendered

View3D Ctrl+Backspace
-> view.input
-> ControllerService
-> model.clearSelection
-> ModelService selection output state
-> scene.frame selection.type/id cleared
-> View3D view.frameRendered

View3D KeyDown H
-> view.input
-> ControllerService
-> model.setSelection
-> ModelService selection output state
-> scene.frame selection.type=star, selection.id=celestia:star:Sol
-> View3D view.frameRendered

View3D KeyDown C
-> view.input
-> ControllerService
-> model.centerSelection
-> ModelService camera output state
-> scene.frame camera/observer position centered
-> View3D view.frameRendered

View3D KeyDown Left
-> view.input
-> ControllerService
-> model.orbitCamera
-> ModelService camera orientation output state
-> scene.frame camera.orientation changed
-> View3D view.frameRendered
```

这些闭环证明 Controller 不再只是把 View 输入摘要转发给 Model，而是可以把输入翻译成 typed model command，并让下一帧场景状态发生可验证变化。

## 4. 实现说明

### 4.1 Controller 输入翻译

`ControllerService` 对 `view.input` 增加第一条 typed command 规则：

```text
device=keyboard
action=KeyDown
key=Space
```

输出：

```text
name=model.setPaused
payload=paused=true|false;view=celestia.view3d.opengl;command=time.pause
```

`KeyDown L` 输出：

```text
name=model.setTimeScale
payload=timeScale=2.000000;view=celestia.view3d.opengl;command=time.setScale
```

`MouseWheel` 输出：

```text
name=model.setCameraFov
payload=fov=40.000000;view=celestia.view3d.opengl;command=camera.zoom
```

`Ctrl+Backspace` 输出：

```text
name=model.clearSelection
payload=view=celestia.view3d.opengl;command=selection.clear
```

`Ctrl+Backspace` 是 Step16 typed command 验证入口，用于证明选择状态清空可以通过协议闭环传递；它不声明已经完成历史 Celestia UI 快捷键语义迁移。

`KeyDown H` 输出：

```text
name=model.setSelection
payload=type=star;id=celestia:star:Sol;view=celestia.view3d.opengl;command=selection.selectObject
```

`KeyDown H` 当前沿用历史 Celestia 中 H 选择主星/太阳的方向，用于证明对象选择状态可以通过协议闭环传递；它还不是鼠标拾取、浏览器选择或任意对象解析系统。

`KeyDown C` 输出：

```text
name=model.centerSelection
payload=target=currentSelection;view=celestia.view3d.opengl;command=camera.center
```

`KeyDown C` 当前沿用历史 Celestia 中 C center selection 的方向，用于证明相机输出状态可以通过协议闭环改变；它还不是完整旅行动画、参考系、距离估算或真实 observer motion 迁移。

`KeyDown Left` 输出：

```text
name=model.orbitCamera
payload=target=currentSelection;yawDegrees=-15.000000;view=celestia.view3d.opengl;command=camera.orbit
```

`KeyDown Left` 当前用于证明相机方向输出状态可以通过协议闭环改变；它还不是完整历史 Celestia orbit 控制、鼠标拖拽、参考系、距离约束或真实 observer motion 迁移。

非 Space、L、MouseWheel、Ctrl+Backspace、H、C 的普通 `view.input` 继续走 Step8 的 `model.setViewInput` 摘要路径，保持兼容。

### 4.2 Model 状态投影

`ModelService` 在生成 `view.frame` 或 `scene.frame` 前，把 service 层状态覆盖到 `ViewFrame`：

```text
paused_
timeScale_
```

因此 `model.setPaused` 如果携带 3D view 语义，会直接返回 `scene.frame`，并在 `time.paused` 中体现状态变化。

`model.setCameraFov` 当前只覆盖输出协议中的 `ViewFrame.camera.fovDeg`，用于证明 Controller 到场景帧的相机输出闭环；它还不是历史 Celestia 相机对象的完整迁移。

`model.clearSelection` 当前覆盖输出协议中的 `ViewFrame.selections` 与 `SceneFrame.selection`，用于证明选择状态可以被 Controller typed command 清空并被 View3D 消费；它还不是完整对象选择、拾取或历史选择导航语义迁移。

`model.setSelection` 当前覆盖输出协议中的 `ViewFrame.selections` 与 `SceneFrame.selection`，用于证明指定对象 id 可以从 Controller typed command 进入场景帧；它还不是完整对象解析、点击拾取或选择浏览器迁移。

`model.centerSelection` 当前覆盖输出协议中的 `ViewFrame.camera.positionKm`、`ViewFrame.observer.positionKm`、`SceneFrame.camera.position` 与 `SceneFrame.observer.position`，用于证明相机位置输出可以被 Controller typed command 改变；它还不是完整历史 Celestia `centerSelection()` 运动模型迁移。

`model.orbitCamera` 当前覆盖输出协议中的 `ViewFrame.camera.orientation` 与 `SceneFrame.camera.orientation`，用于证明相机方向输出可以被 Controller typed command 改变；它还不是完整历史 Celestia orbit/observer 运动模型迁移。

### 4.3 RuntimeSession 输入路由

`RuntimeSession::routePendingViewInputs` 不再把 Controller 输出限制为 `model.setViewInput`，而是接受任意发往 Model 的 command。

保留的限制：

```text
targetRole must be Model
kind must be Command
model response must still be scene.frame for View3D path
```

这样既保留 Step8 的输入摘要路径，也允许 Step16 typed command 进入真实 Model 状态。

## 8. 边界结论

Step16 当前完成的是时间控制、camera.zoom、camera.center、camera.orbit、selection.clear 和 selection.selectObject 输出协议闭环，不是完整交互系统。

可以说：

```text
View3D Space key input can be translated by Controller into model.setPaused.
ModelService applies the pause state and emits scene.frame time.paused=true.
View3D L key input can be translated by Controller into model.setTimeScale.
ModelService applies the timeScale state and emits scene.frame time.timeScale=2.
View3D MouseWheel input can be translated by Controller into model.setCameraFov.
ModelService applies the camera FOV output state and emits scene.frame camera.fov=40.
View3D Ctrl+Backspace input can be translated by Controller into model.clearSelection.
ModelService clears the selection output state and emits empty scene.frame selection.type/id.
View3D H key input can be translated by Controller into model.setSelection.
ModelService applies the selected Sol object id and emits scene.frame selection.type=star selection.id=celestia:star:Sol.
View3D C key input can be translated by Controller into model.centerSelection.
ModelService applies the centered camera output state and emits scene.frame camera/observer position z=4.
View3D Left key input can be translated by Controller into model.orbitCamera.
ModelService applies the camera yaw output state and emits changed scene.frame camera.orientation.
View3D receives the updated scene.frame and renders a frame acknowledgement.
RuntimeSession can route typed Controller model commands, not only model.setViewInput.
```

不能说：

```text
所有 Step16 命令已经完成。
相机、选择、导航和 observer follow 已经具备真实 Celestia 语义。
跨进程 View3D 已达到完整交互和视觉保真。
```
