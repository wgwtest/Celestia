# Celestia MVC Step16 Real Controller Interaction Loop Implementation Notes

日期：2026-06-27

## 1. 目标

Step16 的目标是把 `View input -> Controller command -> Model state -> scene.frame -> View` 做成真实闭环。

本轮实现第一条可验证闭环：

```text
View3D KeyDown Space
-> view.input
-> ControllerService
-> model.setPaused
-> ModelService paused state
-> scene.frame time.paused=true
-> View3D view.frameRendered
```

这条闭环证明 Controller 不再只是把 View 输入摘要转发给 Model，而是可以把输入翻译成 typed model command，并让下一帧场景状态发生可验证变化。

## 4. 实现说明

### 4.1 Controller 输入翻译

`ControllerService` 对 `view.input` 增加第一条 typed command 规则：

```text
device=keyboard
action=KeyDown
key=Space
```

输出：

```text
name=model.setPaused
payload=paused=true|false;view=celestia.view3d.opengl;command=time.pause
```

非 Space 的普通 `view.input` 继续走 Step8 的 `model.setViewInput` 摘要路径，保持兼容。

### 4.2 Model 状态投影

`ModelService` 在生成 `view.frame` 或 `scene.frame` 前，把 service 层状态覆盖到 `ViewFrame`：

```text
paused_
timeScale_
```

因此 `model.setPaused` 如果携带 3D view 语义，会直接返回 `scene.frame`，并在 `time.paused` 中体现状态变化。

### 4.3 RuntimeSession 输入路由

`RuntimeSession::routePendingViewInputs` 不再把 Controller 输出限制为 `model.setViewInput`，而是接受任意发往 Model 的 command。

保留的限制：

```text
targetRole must be Model
kind must be Command
model response must still be scene.frame for View3D path
```

这样既保留 Step8 的输入摘要路径，也允许 Step16 typed command 进入真实 Model 状态。

## 8. 边界结论

Step16 当前完成的是第一条真实 Controller 闭环，不是完整交互系统。

可以说：

```text
View3D Space key input can be translated by Controller into model.setPaused.
ModelService applies the pause state and emits scene.frame time.paused=true.
View3D receives the updated scene.frame and renders a frame acknowledgement.
RuntimeSession can route typed Controller model commands, not only model.setViewInput.
```

不能说：

```text
所有 Step16 命令已经完成。
相机、选择、导航和 observer follow 已经具备真实 Celestia 语义。
跨进程 View3D 已达到完整交互和视觉保真。
```
